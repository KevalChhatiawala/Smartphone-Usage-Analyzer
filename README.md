# 📱 Smartphone Usage Analyzer

AI-powered web application that analyzes smartphone addiction risk using Machine Learning.

## 🚀 Features
- User Authentication (Login/Register)
- Admin Dashboard
- ML-based Risk Prediction
- Personalized Suggestions
- Usage History Tracking

## 🛠️ Tech Stack
- Backend: Flask
- Frontend: HTML, CSS, JavaScript
- ML: Scikit-learn
- Database: SQLite

## ⚡ How to Run

```bash
pip install -r requirements.txt
python app.py
